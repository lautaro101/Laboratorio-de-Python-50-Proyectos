# Python-Laboratorio1-Fundamentos

**Mi ruta de aprendizaje en Python - Laboratorio 1 de 8**

Este repositorio contiene los primeros 10 proyectos de mi plan integral de 50 proyectos para dominar Python, SQL y el desarrollo de software.

El objetivo principal de esta primera etapa es construir una base lógica sólida y dominar las herramientas fundamentales del lenguaje mediante la resolución de problemas reales en aplicaciones de consola, preparando el terreno para las estructuras de datos, el diseño modular y la Programación Orientada a Objetos (POO).

## Conceptos Aplicados en esta Etapa

Durante el desarrollo de estos proyectos, puse en práctica los siguientes fundamentos:

* Declaración de Variables y manejo de Tipos de Datos (`int`, `float`, `str`, `bool`).
* Entrada y Salida de datos interactiva (`input()`, `print()`).
* Conversiones y parseo de tipos de datos (Casting explícito).
* Operadores aritméticos, relacionales y lógicos (`and`, `or`, `not`).
* Estructuras de control de flujo y decisión (`if`, `elif`, `else`).
* Estructuras iterativas y bucles condicionales (`while`).
* Estructuras iterativas y bucles definidos (`for`, `range()`).
* Lógica algorítmica fundamental: Uso de Acumuladores y Contadores dentro de ciclos.
* Complejidad estructural: Ciclos anidados y condicionales anidados (estructuras dentro de otras estructuras).
* Organización inicial del código: Primer acercamiento al uso de funciones (`def`) para encapsular comportamientos repetitivos.
