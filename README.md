# 🚀 Mi Ruta de Aprendizaje: 50 Proyectos en Python + SQL

Este repositorio documenta mi progreso resolviendo **50 proyectos prácticos** de desarrollo de software utilizando Python como lenguaje principal y SQL para la gestión de bases de datos. 

El objetivo de este desafío no es simplemente aprender sintaxis, sino desarrollar la capacidad analítica para resolver problemas reales. A lo largo de esta ruta, evolucionaré desde la escritura de algoritmos básicos en consola hasta el diseño y construcción de un sistema de gestión integral (ERP) conectado a una base de datos relacional.

## 🎯 Enfoque y Metodología

Para garantizar un aprendizaje sólido y profesional, este repositorio se rige por los siguientes principios:
* **Problemas Reales:** Los proyectos simulan casos de uso del mundo real (gestión de stock, presupuestos, turnos, sistemas empresariales).
* **Progresión Lógica:** Cada proyecto introduce conceptos nuevos basándose estrictamente en lo aprendido en los laboratorios anteriores.
* **Bases Sólidas antes de la Magia:** Aprendizaje de SQL puro y diseño de bases de datos relacionales antes de introducir abstracciones u ORMs.
* **Calidad de Código (Clean Code):** Énfasis progresivo en el diseño modular, la Programación Orientada a Objetos (POO), el manejo defensivo de errores (casos límite) y la separación de responsabilidades.

## 📌 Mapa de Laboratorios (Roadmap)

El trayecto está estructurado en 8 grandes etapas. Cada carpeta contiene su propia documentación detallada y sus respectivos proyectos:

- [ ] **Laboratorio 1: Fundamentos de Python (Proyectos 1 al 10)**  
  *Variables, tipos de datos, condicionales lógicos, operaciones matemáticas y ciclos (`while`, `for`).*

- [ ] **Laboratorio 2: Estructuras de Datos (Proyectos 11 al 18)**  
  *Manipulación y organización de información utilizando Listas, Tuplas, Diccionarios y Conjuntos.*

- [ ] **Laboratorio 3: Diseño Modular (Proyectos 19 al 25)**  
  *Creación de funciones, paso de parámetros, retornos y separación del código en múltiples archivos/módulos.*

- [ ] **Laboratorio 4: Python Intermedio (Proyectos 26 al 33)**  
  *Manejo de excepciones (`try/except`), lectura/escritura de archivos (`.txt`, `.json`), type hints y funciones avanzadas.*

- [ ] **Laboratorio 5: Introducción a POO (Proyectos 34 al 40)**  
  *Paradigma de objetos: Clases, atributos, métodos, encapsulamiento, herencia, polimorfismo y composición.*

- [ ] **Laboratorio 6: POO Aplicada (Proyectos 41 al 43)**  
  *Modelado de sistemas completos en consola con múltiples objetos interactuando entre sí bajo reglas de negocio estrictas.*

- [ ] **Laboratorio 7: SQL y Bases de Datos (Proyectos 44 al 47)**  
  *Diseño relacional, normalización, consultas SQL puras (`SELECT`, `JOIN`, agregaciones) y conexión nativa con Python.*

- [ ] **Laboratorio 8: Proyectos Integradores (Proyectos 48 al 50)**  
  *Arquitectura en capas, persistencia de datos robusta y desarrollo de aplicaciones CRUD complejas para pequeños negocios.*
